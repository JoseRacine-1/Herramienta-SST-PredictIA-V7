# Datos de entrada

En esta carpeta debe ubicarse la base de datos limpia postunificación requerida para ejecutar la Herramienta V7.

Por razones de tamaño, privacidad y control de uso, la base de datos completa no se incluye en el repositorio.

La herramienta espera un archivo CSV con las variables requeridas para el procesamiento, entrenamiento, predicción, clasificación y generación de resultados.

Para acceder a la base de datos debes tener permiso autorizado: https://drive.google.com/drive/folders/1VOcWtuReIb4u9ri0dq_wdfSZHJ_NbZ3v?usp=drive_link
